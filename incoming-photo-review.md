## Metadata and processing decisions

- Preserve all originals in `incoming-photos/`; never rename or overwrite them.
- Generate AVIF, WebP and JPEG outputs only from the reviewed import manifest.
- Use the recommended cover and anchor frames to lead each story, while retaining all other frames in their chronological gallery sequence.
- Use unique SEO-friendly destination names even for near-duplicate sequences.
- Keep descriptive alt text for meaningful images. Use an empty alt string only when an image is deliberately decorative or repeats the same information immediately beside it.
- Default focal points to `50% 50%`; override only where the subject would otherwise be cropped. Portrait photographs generally need a slightly higher mobile focal point around `50% 40%`.
